========================================================
6. PRODUCTION SCORING ENGINE
========================================================

SCORE =

+ metro access
+ bus access
+ grocery density
+ breakfast density
+ gym proximity
+ park proximity
+ road connectivity
+ green cover

- congestion
- slum proximity
- industrial noise
- labour cluster penalty

Normalize => 0 to 100

========================================================
7. BEST GEO COMPUTATION MODEL
========================================================

DO NOT calculate per pixel.

Use H3 Hexagonal Grid.

Flow:

1. Divide Bangalore into H3 cells
2. Calculate score per cell
3. Store in grid_scores
4. Render colored hexagons

Benefits:
- scalable
- cacheable
- beautiful visuals
- zoom friendly

13. DATA INGESTION PIPELINE
========================================================

Nightly Job:

1. Pull OSM places
2. Clean duplicates
3. Categorize nodes
4. Store in places table
5. Trigger score recompute

========================================================
15. RECOMPUTE ENGINE
========================================================

When data changes:

- recompute affected H3 cells only
- not whole city

Huge cost saver.
