PHASE 1 IMPLEMENTATION PLAN (POC)
PROJECT GOAL:
Create a simple web application that opens a map, shows city view, supports search, marker placement, and displays a mock heatmap overlay.

==================================================
1. PHASE 1 SCOPE
==================================================

Deliver only:

[ ] Web application
[ ] Full screen interactive map
[ ] Search place/locality
[ ] Center map to searched location
[ ] Click map to drop marker
[ ] Show popup with coordinates
[ ] Toggle demo heatmap layer
[ ] Basic responsive layout
[ ] Use only free APIs / free tokens

No backend required in phase 1.
