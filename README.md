# Hotspot

A Phase 1 proof-of-concept interactive map web app built with Next.js, TypeScript, Tailwind CSS, and MapLibre GL JS.

## Features

- Full-screen Bangalore map view
- Search with free Nominatim API
- Fly to searched location and place a marker
- Click map to display coordinates
- Toggle mock heatmap overlay for Bangalore hotspots
- Responsive layout for desktop and mobile

## Setup

```bash
npm install
npm run dev
```

Open `http://localhost:3000` after startup.
